## 目标

优化设备卡片的设备信息布局为两列网格，重新设计流程快捷按钮的布局规则和颜色状态映射。

## 设计

### 一、设备信息：1 行 2 列网格

用 `Row gutter={[8, 4]}` 包裹 4 个 `Col span={12}`，替换当前的 ad-hoc Row/Col 布局。

```
┌──────────────────────────────────────────┐
│  芯片: esp32-001    │  电压: 3.30V (计算) │
│  网卡: aa:bb:cc:dd  │  状态: ●在线        │
└──────────────────────────────────────────┘
```

- 第 1 行：芯片 / 电压
- 第 2 行：网卡 / 状态
- 电压行：仅当 `voltage !== undefined` 时渲染

### 二、流程快捷按钮

#### 布局规则

- 偶数个流程（2、4、6…）：每行 2 个，等宽 `Col span={12}`
- 奇数个流程（3、5…）：第 1 个占一整行 `Col span={24}`，剩余按每行 2 个

```
3 个流程：              5 个流程：
┌──────────────────┐   ┌──────────────────┐
│  流程A            │   │  流程A            │
├────────┬─────────┤   ├────────┬─────────┤
│ 流程B  │  流程C   │   │ 流程B  │  流程C  │
└────────┴─────────┘   ├────────┼─────────┤
                        │ 流程D  │  流程E  │
                        └────────┴─────────┘
```

#### 颜色/状态映射

| 状态 | 条件 | 按钮样式 | 文案 | 可点击 |
|------|------|---------|------|--------|
| 运行中 | `switch === "on"` 且 `index` 匹配 | `type="primary" danger` 红色 | 停止 | ✅ |
| 已停止 | `switch === "off"` 或 `index` 不匹配 | `type="primary"` 蓝色 | 流程名 | ✅ |
| 待机中 | `idleSleep === true` 且非运行中 | `disabled` 灰色 | 流程名 | ❌ |

#### 交互

纯单击切换：
- 点击运行中的按钮 → 调用 `setDeviceSwitch` 终止流程
- 点击已停止的按钮 → 调用 `setDeviceSwitch` 启动流程
- 待机中的按钮不可点击

### 三、移除的内容

- 流程按钮上的 `Dropdown` 右键菜单包装
- 卡片上方"运行中: xxx"的蓝色文字提示行（按钮自身状态已标示）
- `MoreOutlined` 图标导入（不再使用）
- 编辑流程功能通过卡片右上角"配置"按钮覆盖

## 不变的内容

- 卡片右上角操作按钮（日志、配置、清除、删除）
- 电压计算公式 `V_actual = V_sensor * (R1 + R2) / R2`
- `onClickSwitch` 核心逻辑（只是按钮 UI 改变）
- 设备离线时隐藏流程按钮
- 无流程时不显示按钮区域
